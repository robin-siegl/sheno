# Sheno identity

The approved symbol is an S formed from two curved capsule-like shapes. The native vector paths were traced from the approved indigo concept. The brand color is #5B50D6.

`logo-indigo.svg`, `logo-black.svg` and `logo-white.svg` are vector sources, with PNG equivalents. Android uses the same path for the in-app mark, notification icon, adaptive launcher icon and monochrome themed icon. Dev builds invert the launcher colors.

Use the monochrome foreground when Android applies a themed icon palette. Preserve the silhouette and inner spacing when exporting at different sizes. A standalone wordmark font has not been selected; the application uses system typography.
