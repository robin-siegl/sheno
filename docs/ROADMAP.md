# Roadmap

## 0.1.0: Personal tracking

Native Material 3 screens, colored medication shapes, schedules, intake history, inventory, reminders, order links and browser copy prototype, basic Today widget, Android backup and manual export/import. GitHub dev and signed production build workflows.

Before the first production release, test reminder delivery and backup restore on the Pixel 10 Pro, including device restart, idle mode, permission changes, daylight saving changes and time zone changes. Test the ordering toolbar on the actual ordering website and installed browser.

## Following releases

- Refine reminder and widget behavior from device feedback
- Additional widgets and widget configuration
- Optional biometric app lock
- More flexible schedules, including explicitly configured hourly intervals and cycles
- Better history filtering and export summaries
- Accessibility review at large font sizes and on narrow screens

Sheno remains a personal organizer. Medical advice, treatment recommendations, drug identification and automatic ordering are outside its scope. Distribution stays on GitHub.
